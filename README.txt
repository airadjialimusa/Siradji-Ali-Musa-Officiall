OFFICIAL SIRADJI ALI MUSA — GITHUB PAGES WEBSITE

Upload these files and folders to the ROOT of a PUBLIC GitHub repository:
- index.html
- assets/official-logo.jpg
- .nojekyll

Then open repository Settings > Pages.
Under Build and deployment:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
Click Save.

Your free GitHub Pages address will be:
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/

For the clean account-level address:
https://YOUR-GITHUB-USERNAME.github.io/
the repository must be named exactly YOUR-GITHUB-USERNAME.github.io.

GitHub Pages hosts static files only. This package is a frontend prototype;
AI generation, accounts, database, uploads and admin features are not yet
connected to a backend. Do not upload private keys or passwords.
